규칙을 불러오는 중…

자동 복사가 제한되면 전체 선택 후 Mac은 ⌘+C, Windows는 Ctrl+C를 누르세요.

2. Firestore 규칙에 붙여 넣고 게시하세요

Firebase의 Firestore 규칙 화면 열기 → 편집창 안 클릭 → 전체 선택(⌘+A 또는 Ctrl+A) → 붙여넣기 → 게시.

전체 규칙을 교체하되 관리자용 members, events 보호 규칙은 위 코드에 그대로 포함되어 있습니다. 데이터베이스 전체를 공개하지 않고 sharedPlans/snu60만 임시 수정하도록 허용합니다. GitHub 파일을 바꾸는 것만으로 Firebase 서버 규칙이 게시되지는 않습니다.

3. 사이트에서 저장 확인

좌석 편집기 열기 → 초기 배치 공동 저장 → 공동 저장 완료 표시를 확인하세요. 이후 사람이나 테이블을 옮기면 자동 저장됩니다.

다른 브라우저와 새로고침 후에도 같은 배치인지 확인하세요. 첫 저장 전에는 초기 배치안을 보여주며, 서버에 저장된 배치가 있으면 그것을 우선 사용합니다. events/snu60의 옛 관리자용 데이터와 자동 병합하지 않습니다.

변경 이력은 삭제·수정할 수 없도록 규칙으로 보호합니다. 다만 공개 편집자는 잘못된 좌석 배정이나 원치 않는 명단 변경을 할 수 있고, 방문자 표시는 실명 인증이 아닙니다. 행사 전에 백업 JSON도 보관해 두세요.
