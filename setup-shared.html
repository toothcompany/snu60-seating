로그인 없이 공동 저장하기

링크를 받은 사람은 누구나 이름·소속·좌석 배치를 변경할 수 있습니다. 방문자는 계정이나 비밀번호를 입력하지 않지만, 앱 내부에서는 익명 인증으로 방문자를 자동 연결합니다. 기존 관리자 이메일 목록과 관리자 전용 기록은 공개하지 않습니다.

1. 익명 사용 설정

Firebase 로그인 방법 열기 → 새 제공업체 추가 → 익명 → 사용 설정 → 저장.
기존 Google 설정과 members 관리자 문서는 지우지 않아도 됩니다.

2. Firestore 규칙 교체·게시

아래 규칙 전체 복사를 누르고 Firestore 규칙 탭에서 기존 코드 전체를 선택해 붙여 넣은 뒤 게시를 누르세요. 웹페이지 코드 업데이트만으로 서버 규칙이 자동 게시되지는 않습니다.

규칙을 불러오는 중…

복사가 차단되면 전체 선택 버튼을 누른 뒤 Mac은 ⌘+C, Windows는 Ctrl+C로 복사하세요. allow read, write: if true로 데이터베이스 전체를 열지 않습니다.

3. 사이트에서 저장 확인

좌석 편집기 열기 → 새로고침 → 연결 완료를 확인하고 초기 배치 공동 저장을 누르세요. 이후 사람이나 테이블을 옮기면 자동 저장합니다.

다른 브라우저에서도 같은 배치가 표시되는지 확인하세요. 공동 저장 완료 표시가 없으면 저장됐다고 판단하지 마세요. 이메일·전화번호·주소를 참석자 정보에 입력하지 마세요.

이번 공동 배치는 sharedPlans/snu60에 저장합니다. 기존 events/snu60의 비공개 데이터와 자동 병합하지 않습니다. 규칙은 허용된 형태와 변경 이력을 검사하지만, 링크를 가진 사람의 잘못된 배정까지 막지는 않습니다. 행사 종료 후에는 익명 편집 접근을 닫고 JSON 백업을 보관하세요.
