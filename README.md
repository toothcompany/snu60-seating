# 예방치학교실 60주년 · 함께 만드는 자리

**공동 편집 사이트:** https://toothcompany.github.io/snu60-seating/

**마지막 설정 안내:** https://toothcompany.github.io/snu60-seating/setup-shared.html

## 이번 행사 운영 방식

사용자가 단기간의 행사 좌석표에 대해 로그인 없는 조회·편집·공동 저장을 명시적으로 요청했습니다. 기본 페이지에는 계정 선택이나 비밀번호 입력이 없으며, Firebase 익명 로그인 제공업체 설정도 필요 없습니다.

- 이름을 다른 원으로 끌어 참석자 이동, 다른 이름 위에 놓아 자리 교환
- 원형 테이블을 명단과 함께 이동, 테이블 전체 위치 교환
- 정원 초과 빨강 / 미달 파랑 / 일치 기본색
- 오른쪽 이름·소속 명단, 검색·필터
- Firestore 공동 저장, 충돌 검사, 저장 성공 표시
- 변경 직전 배치의 이력과 복원, JSON 백업 및 CSV 내보내기

## 반드시 한 번 적용할 서버 설정

설정 안내 페이지의 **규칙 전체 복사** → Firebase Firestore **규칙** 탭에 전체 붙여넣기 → **게시**.

GitHub 배포와 Firebase 서버 규칙 게시는 별개입니다. 실제 저장은 규칙 게시 후 `공동 저장 완료`와 새로고침·다른 브라우저 테스트로 확인하세요. 코드 배포만으로 서버 설정이 완료됐다고 판단하지 않습니다.

## 임시 편집 기한

**2026년 11월 16일 00:00 한국시간**부터 서버가 공개 편집 요청을 거절합니다. 기한은 Firestore 서버의 request.time으로 확인합니다. 이후에는 조회·백업만 남습니다. 데이터나 이미 배포된 명단을 자동 삭제하는 기능은 아닙니다.

## 초기 배치와 공개 범위

최종 참석자 99명과 추가 요청 1명을 포함한 100명 중, 학술행사만 참석하는 1명은 만찬 미배정입니다. 만찬은 12개 테이블 99석(1~9번 각 8석, 10~12번 각 9석)입니다. 서버에 이미 저장된 배치가 있으면 그것이 우선이며, 초기 배치로 자동 덮어쓰지 않습니다.

공개 항목은 이름·소속·좌석입니다. 연락처·주소·관리자 이메일·상세 응답은 넣지 않습니다. 사용자 요청에 따라 초기 명단은 public-plan.mjs에 포함되어 있으므로 그 코드와 과거 커밋도 공개됩니다.

`sharedPlans/snu60`만 공개 공동 편집합니다. 기존 관리자용 `members`, `events/snu60`은 역할 기반 제한을 유지합니다. 공개 편집자에게 관리자 권한을 주지 않습니다.

아무나 명단이나 좌석을 잘못 바꿀 위험과 사용량 남용 위험은 남습니다. 브라우저 식별번호는 임의 표식이며 실명 인증이 아닙니다. 이력/백업은 복구 수단이지 모든 악용을 방지하는 수단은 아닙니다.

## 문서와 검사

최신 운영 설명은 [SHARED_EDITING.md](./SHARED_EDITING.md)를 따릅니다. `SETUP.md`, `PUBLIC_SETUP.md`와 `editor.html`은 이전 운영진 전용/공개조회 버전의 기록이며 현재 공동 좌석표와 자동 병합하지 않습니다.

```sh
npm run check
npm test
```

기본 검사는 명단·정원·인접 좌석·테이블 교환·충돌 방지·KST 기한을 확인합니다. Firestore 에뮬레이터 검사는 비로그인 저장, 서버 기한, 필수 이력, 비공개 데이터 차단을 확인합니다. 운영 서버의 규칙 게시와 실제 두 브라우저 동기화는 별도로 확인해야 합니다.
