# 예방치학교실 60주년 · 좌석 배치도

## 주소

- **로그인 없는 공개보기:** https://toothcompany.github.io/snu60-seating/
- **운영진 로그인·편집:** https://toothcompany.github.io/snu60-seating/editor.html

2026년 11월 10일, 사용자가 최종 참석자 명단과 수정 요청을 반영하고 로그인 없이도 볼 수 있도록 요청하여 **이름·소속/비고·좌석에 한정한 공개보기**를 추가했습니다.

## 초기 배치

최종 파일의 참석 99명에 별도 추가 요청 1명을 반영해 총 100명입니다. 학술행사만 참석하는 1명은 만찬 미배정으로 두고, 12개 테이블에 99명을 배치했습니다. 1~9번 정원 8명, 10~12번 정원 9명이며 초기 배치의 정원은 모두 일치합니다.

테이블 위치 교환, 고정해야 하는 두 사람의 물리적 좌석, 앞줄 혼합, 연속 좌석, 이름 정정과 업체 인원 변경을 자동검사합니다. 상세 반영 기준은 [PUBLIC_SETUP.md](./PUBLIC_SETUP.md)에 있습니다.

## 공개보기

- 로그인 없이 이름·소속/비고 검색, 테이블별 명단과 좌석 확인
- 공개 CSV/JSON 다운로드와 인쇄/PDF
- Firebase 연결 전에도 최신 초기 배치안 표시
- 공개용 보안 규칙과 운영진 초기 등록 완료 후 `publicPlans/snu60` 실시간 보기
- 실시간 연결 전에는 **현재 고정본**이라고 명확히 표시

## 운영진 편집

- 참석자 이름을 다른 테이블로 드래그하거나 이름 위에 놓아 자리 교환
- 테이블 원을 드래그해 명단과 함께 이동, 테이블 위치 교환
- 정원 초과 빨강 / 정원 미달 파랑 / 정원 일치 기본색
- Google 로그인 + 승인된 운영진만 수정
- Firestore 공동 저장, 충돌 감지, 상태 표시, 변경 이력과 되돌리기
- 최초 한 번 **11월 10일 배치안 적용**으로 새 명단 불러오기

## 반드시 구분할 상태

초기 공개보기의 코드 배포와 실제 Firestore 서버 규칙 게시는 별개입니다. 최신 `firestore.rules`를 Firebase 콘솔에서 게시해야 편집 변경도 익명 공개화면에 동기화됩니다. 초기 배치안은 이 설정 전에도 공개보기에서 열립니다.

기존 `SETUP.md`는 최초 비공개 버전의 기록입니다. **공개보기 관련 최신 설정은 [PUBLIC_SETUP.md](./PUBLIC_SETUP.md)를 우선합니다.**

## 데이터 보호

공개 저장소에는 승인된 공개 명단(`public-plan.mjs`)이 들어 있습니다. 연락처·주소·관리자 이메일·계정 비공개 키·상세 응답 메모는 포함하지 않습니다. 운영진 정보와 변경 이력은 공개 조회 대상이 아닙니다. 검색엔진 `noindex`는 접근 제한을 대신하지 않습니다.

## 검사

```sh
npm run check
npm test
```

모델 검사에는 원명단의 참석자 ID 전체 대조, 99석 정원, 가족 구분, 특정인 옆자리·이동·물리적 위치 유지와 공개 필드 제한이 포함됩니다. 별도 브라우저 워크플로는 Firebase 연결과 로그인 없이 PC·모바일 공개표시, 검색·필터, 비로그인 편집 잠금을 확인합니다. 실제 공동 저장과 배포된 Firebase 규칙의 검증은 운영진 로그인 환경에서 별도로 확인해야 합니다.
