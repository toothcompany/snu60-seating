# 예방치학교실 60주년 · 좌석 편집기

운영진이 참석자와 원형 테이블 배치를 함께 편집하는 웹 앱입니다.

## 기능

- 참석자 이름 드래그로 테이블 이동, 다른 이름 위로 드롭하여 자리 교환
- 원형 테이블을 명단과 함께 이동, 두 테이블 위치 교환
- 정원 초과 빨강 / 정원 미달 파랑 / 정원 일치 기본색
- 참석자 성명·소속을 별도 표시하는 명단, 검색과 테이블 필터
- Google 로그인 + 승인된 운영진만 실제 명단 접근
- Firestore 실시간 공동 저장, 버전 기반 충돌 감지, 저장 상태 표시
- XLSX·CSV·JSON 명단 가져오기, CSV 내보내기와 JSON 백업
- 변경 이력, 다른 변경이 없는 경우 내 마지막 변경 취소
- 실제 개인정보 없는 99석 가상 명단 연습

## 설정 상태

웹 앱 코드와 Firebase 웹 연결 설정은 추가되어 있습니다. **이것만으로 배포나 공동 저장이 완료되는 것은 아닙니다.**

프로젝트 소유자가 다음을 설정해야 합니다.

1. Firebase Authentication에서 Google 로그인 활성화 및 `toothcompany.github.io` 승인된 도메인 추가
2. Firestore `(default)` 데이터베이스 생성 후 [firestore.rules](./firestore.rules) 게시
3. `members` 컬렉션에 승인할 Google 이메일을 문서 ID로 등록하고 `role: admin/editor/viewer` 설정
4. GitHub Settings → Pages → `main` / `/(root)` 게시
5. 운영진 로그인 후 최종 수정 명단을 비공개 데이터베이스에 불러오기

자세한 화면 순서와 확인 방법은 [SETUP.md](./SETUP.md)를 참고하세요.

## 개인정보

실제 참석자 명단, 운영진 이메일 목록, 비공개 키는 이 공개 저장소에 포함하지 않습니다. Firebase 웹 앱 설정은 공개 식별 정보이며, 데이터 접근은 Firestore 보안 규칙이 제한합니다. 가상 명단 연습은 브라우저 메모리에서만 실행되어 공동 저장되지 않습니다.

기존 행사 명단에 대한 개별 성명 정정·동반자 변경·의전 배정안은 공개 코드에 기록하지 않으며, 별도 최종 명단에서 반영해 가져와야 합니다.

## 개발 확인

```sh
npm run check
npm test
```

모델 테스트는 문법, 인원 보존, 좌석 이동, 정원 색상 판정, 충돌 방지, CSV/엑셀 행 가져오기를 확인합니다. 실제 두 사용자 로그인과 실시간 저장, 보안 규칙 및 모바일 화면은 Firebase 설정 후 별도 검증해야 합니다.
